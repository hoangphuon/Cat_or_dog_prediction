# Security Policy

## Supported Versions

This project is currently under development for learning and experimentation purposes. Security updates are not guaranteed for any specific version

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it by opening a GitHub Issue in this repository.

Please include:
- A clear description of the potential vulnerability.
- Steps to reproduce the issue, if applicable.
- Any relevant logs or screenshots.

This project is maintained as a learning project, so response times may vary. Please do not include passwords, API keys, personal information, or other sensitive data in public issues.
